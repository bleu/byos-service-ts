# Domain Docs

This is a single-context repository. Before exploring or changing an area:

- Read root `CONTEXT.md`.
- Read the ADRs in `docs/adr/` relevant to that area.
- Read the normative shared specification in `docs/shared/` when behavior is in scope.

Use the glossary's vocabulary in code, tests, issues, and documentation. If a
proposal conflicts with an ADR, surface the conflict explicitly; the shared
specification remains normative where they disagree.
